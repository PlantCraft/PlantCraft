# PlantCraft roadmap

> **Last reviewed:** 2026-10-30 · **Stage:** alpha

Readiness of each app against what tools of its category offer. "Measured" numbers
come from tests and oracles; "estimated" ones are judgement. Detail per product in
each app's own `ROADMAP.md`; the ranked work list is `docs/gaps.md`.

| App | Category | Stage | Version | Detail |
|---|---|---|---|---|
| PlantCraft | The platform: people, groups, access, sources, signals, assets, Desk, Notebooks, the assistant, API v1 | alpha | 0.5 | this file, `docs/gaps.md` |
| Analytics | Signal quality, control loop performance, process models, blocks and algorithms | alpha | 0.5 | `apps/link/ROADMAP.md` |
| Historian | Plant connections (OPC UA, PI Web API, MQTT, Modbus TCP, SQL, CSV) and history | alpha | 0.5 | `apps/historian/ROADMAP.md` |
| View | Dashboards, Process diagrams, trends and scheduled reports | alpha | 0.5 | `apps/view/ROADMAP.md` |
| Alarms | Alarm management (ISA-18.2): rules, notifications, history, performance | alpha | 0.5 | `apps/alarms/ROADMAP.md` |
| Models | Block-diagram models on Modelica, studies, FMUs | alpha | 0.5 | `apps/models/ROADMAP.md` |
| Documents | The plant's documents, searched by words and meaning, cited by the assistant | alpha | 0.5 | `apps/documents/ROADMAP.md` |
| Simulator | OPC UA plant simulator; runs the demo | beta | 0.5 | `simulator/ROADMAP.md` |

Readiness per area (measured or estimated) is in each app's own `ROADMAP.md`.
