# Estatística descritiva

## O que detecta

Nada a julgar: descreve as amostras brutas de PV da janela (quantidade, média, desvio padrão,
mínimo, máximo, percentis 5 e 95) para que uma pessoa confira se os dados são os esperados
(faixa, unidade, escala). Faz parte do filtro de qualidade de dados, mas nunca bloqueia.

## Referência

- Nenhuma: estatística descritiva padrão.

## Parâmetros

Este método não tem parâmetros.

## Como ler o achado

"8640 amostras brutas de PV." Olhe as métricas: uma média ou faixa longe dos valores esperados
aponta para um sinal, unidade ou escala errados no PlantCraft.

## Limites

- Descreve os dados; não julga se são bons ou ruins.
