# Public links

An editor can open **Share** on a dashboard and create a link that shows that dashboard,
read-only, to anyone who has it, without signing in: for a control room screen or a colleague
without an account.

- The link is shown once; copy it then. Dashboards keeps only a fingerprint of it.
- A link opens one dashboard and nothing else, and stops at once when it is revoked or its
  dashboard is deleted.
- The list shows when each link was created and last opened.
- An administrator can turn public links off for the whole installation
  (`DASHCRAFT_PUBLIC_LINKS=false`); they also need the Dashboards app key.
