# Enlaces públicos

Un editor puede abrir **Compartir** en un dashboard y crear un enlace que muestra ese dashboard,
en solo lectura, a cualquier persona que lo tenga, sin iniciar sesión: para una pantalla de sala
de control o un colega sin cuenta.

- El enlace se muestra una sola vez; cópielo en ese momento. Dashboards guarda solo una huella de él.
- Un enlace abre un dashboard y nada más, y deja de funcionar de inmediato cuando se revoca o
  cuando se elimina su dashboard.
- La lista muestra cuándo se creó cada enlace y cuándo se abrió por última vez.
- Un administrador puede desactivar los enlaces públicos para toda la instalación
  (`DASHCRAFT_PUBLIC_LINKS=false`); además necesitan la clave de la app View.
