# One dashboard for many assets

In **Settings**, choose an **Asset picker** (for example "One loop at a time"). Panels can then
name "the dashboard's asset" and a signal role (`pv`, `sp`, `op`, ...) instead of a signal: the
picker at the top of the page chooses the asset, and every panel follows it.

Roles come from the asset records in PlantCraft. When a loop's PV is rewired there, the
dashboard follows. An asset without a role shows the problem on the panel, not a wrong value.

PlantCraft's asset page links here: The Dashboards page for an asset lists the dashboards that
pick assets of its kind and the ones whose panels name it.
