# Um dashboard para muitos ativos

Em **Configurações**, escolha um **Seletor de ativo** (por exemplo "Uma malha por vez"). Os painéis
podem então indicar "o ativo do dashboard" e um papel de sinal (`pv`, `sp`, `op`, ...) em vez de um
sinal: o seletor no topo da página escolhe o ativo, e todos os painéis o seguem.

Os papéis vêm dos cadastros de ativos no PlantCraft. Quando a PV de uma malha é religada lá, o
dashboard acompanha. Um ativo sem o papel mostra o problema no painel, não um valor errado.

A página do ativo no PlantCraft tem um link para cá: a página Dashboards de um ativo lista os
dashboards que escolhem ativos do tipo dele e aqueles cujos painéis o indicam.
