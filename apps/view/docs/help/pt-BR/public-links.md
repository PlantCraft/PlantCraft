# Links públicos

Um editor pode abrir **Compartilhar** em um dashboard e criar um link que mostra esse dashboard,
somente leitura, a qualquer pessoa que o tenha, sem entrar: para uma tela de sala de controle ou um
colega sem conta.

- O link é mostrado uma vez; copie-o nesse momento. O Dashboards guarda só uma impressão digital
  dele.
- Um link abre um dashboard e nada mais, e para de funcionar na hora quando é revogado ou quando o
  seu dashboard é excluído.
- A lista mostra quando cada link foi criado e aberto pela última vez.
- Um administrador pode desativar os links públicos para toda a instalação
  (`DASHCRAFT_PUBLIC_LINKS=false`); eles também precisam da chave de app do View.
