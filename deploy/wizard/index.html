Install PlantCraft on this server

This wizard decides what is fixed before the suite runs: which apps exist, how much of this machine they may use, the network and the security ceilings.

What you choose here is written to /etc/plantcraft/installation.conf, a file only root can change. Administrators inside PlantCraft see these choices as Set by the installation and cannot widen them.

Nothing is downloaded: every image comes from the release bundle this wizard runs from. You can stop at any screen; nothing is changed until the last one.
